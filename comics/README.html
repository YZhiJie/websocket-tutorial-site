WebSocket 漫画课堂 ​

《WebSocket 完全教程》的漫画版支线。用分镜、角色对话把主线 10 章内容演一遍。 所有技术事实、代码、运行输出均与主线教程一致，运行输出来自本机实测。

漫画是路标，源码与实测才是路——看完漫画，记得回主线动手跑代码。

阅读建议 ​

  • 新手：按第一幕到第十幕顺序看，主线章节配合动手实验
  • 复习：第七幕（安全）、第九幕（FAQ）、第十幕（清单）适合上线前快速过一遍
  • 漫画里出现的代码都能在 ../examples/ 找到可运行版本：
bash
cd ../examples
npm install
npm run echo-server     # 第四幕
npm run chat-server     # 第四幕聊天室
npm run secure-server   # 第七幕六道防线
npm run security-test   # 第七幕攻击用例

风格说明 ​

  • 画布统一 1200×800，深蓝黑墨线 #0E1E33 + 科技色板（蓝/青/电光紫/信号黄/警示粉）
  • 每幕 2~4 格分镜，黑底"第X幕"横幅，底部为本幕金句或要点
  • 规范依据以 RFC 6455 为准；详见主线 7.9 节《RFC 6455 协议规范与标准解读》
