第六幕 · 连接续命术 ​

对应主线教程：第 6 章 进阶：心跳、断线重连、鉴权与二进制 配套代码：reconnect-client.js

① 双层心跳 ​

层级机制能发现发现不了
协议级服务端每 10~30s 发 Ping 帧半开 TCP（断网、崩溃）应用假死（内核还在回 Pong）
应用级客户端定时发 {type:'ping'} 等业务回包事件循环卡死、业务 hang——

看门狗核心：超过 8 秒没有任何入站数据（含 Pong）即判定假死，terminate() 主动断开以触发重连。

② 指数退避 + Full Jitter ​

javascript
const cap = Math.min(30_000, 1000 * 2 ** (this.attempt - 1)); // 1→2→4→8…→30s 封顶
const delay = Math.random() * cap;                            // 在 [0, cap] 打散
setTimeout(() => this.connect(), delay);
1
2
3

固定间隔重连会在服务端重启瞬间形成"惊群"，把刚恢复的服务再次打垮。

三个工程细节：

  1. 手动关闭与自动重连互斥：manualClose = true 时退出登录不许自动连回
  2. 重连前清理旧定时器：否则多个看门狗并存，重复 Ping、重复重连
  3. 重连统一在 close 事件处理：error 之后通常紧跟 close，避免触发两次

③ 连接鉴权 ​

javascript
new WebSocket('wss://api.example.com/ws?token=xxx');           // ① Query（仅 wss）
// ② Cookie：浏览器自动携带
new WebSocket('wss://api.example.com/ws', ['bearer', 'xxx']); // ③ 子协议
1
2
3

浏览器 WebSocket API 无法设置 Authorization 头，所以才有子协议传 token 的用法。失败处理：握手阶段返回 401，或建立后立即 close(1008, '鉴权失败')。

④ 二进制与子协议 ​

图片/音频/Protobuf 用二进制帧：浏览器 ws.binaryType = 'arraybuffer'，Node 端直接是 Buffer。new WebSocket(url, ['json','msgpack']) 可协商消息格式，公开子协议有 MQTT、WAMP、STOMP。
