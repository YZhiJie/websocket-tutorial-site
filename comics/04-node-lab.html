② 浏览器原生 API（零依赖） ​

javascript
const ws = new WebSocket('ws://localhost:8080');
ws.onopen = () => { /* 状态灯变绿 */ };
ws.onmessage = (event) => { /* event.data 即消息 */ };
ws.onclose = (event) => { /* event.code 状态码 */ };
ws.onerror = () => { /* 如服务端没启动 */ };

// 发送前必须检查 readyState
if (ws.readyState === WebSocket.OPEN) ws.send(data);

readyState 四态：0 CONNECTING（握手中）→ 1 OPEN（可收发）→ 2 CLOSING → 3 CLOSED。向非 OPEN 连接 send() 会抛异常。

③ 聊天室两大机制 ​

广播：遍历所有连接，只发给 OPEN 的：

javascript
for (const client of wss.clients) {
  if (client.readyState === WebSocket.OPEN) client.send(data);
}

协议级心跳：每 10 秒一轮"先标死、发 Ping、等 Pong 续命"：

javascript
setInterval(() => {
  for (const ws of wss.clients) {
    if (ws.isAlive === false) { ws.terminate(); continue; }
    ws.isAlive = false;
    ws.ping();
  }
}, 10_000);
