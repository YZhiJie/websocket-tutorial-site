第十幕 · 上线前的自检 ​

对应主线教程：第 10 章 生产环境最佳实践清单

连接可靠性 ​

  • [ ] 指数退避 + full jitter 自动重连，成功后重置计数
  • [ ] 区分主动关闭与意外断开，前者不重连
  • [ ] 协议级心跳（服务端）+ 应用级看门狗（客户端）双保险
  • [ ] 每次重连前清理旧定时器
  • [ ] 重连后恢复会话：重新 join 房间、补发丢失期间的消息

消息可靠性 ​

  • [ ] 关键消息应用层 ACK + clientId 幂等去重
  • [ ] 消息体带时间戳/序号，支持对账
  • [ ] 发送前检查 readyState === OPEN，失败消息入队重发

安全 ​

  • [ ] 生产只用 wss://，HTTP 页面跳转 HTTPS
  • [ ] 握手阶段鉴权（401 或 close 1008）
  • [ ] 校验 Origin 防 CSWSH
  • [ ] 限制单 IP 连接数、消息频率与大小
  • [ ] 消息级业务授权；JSON 解析必须 try-catch
  • [ ] 前端用 textContent 渲染用户内容防 XSS

性能与运维 ​

  • [ ] 广播检查 readyState，异常发送用 try-catch 隔离
  • [ ] rAF 批量渲染 + 消息列表窗口化
  • [ ] 大流量考虑二进制协议与消息合并
  • [ ] ulimit -n 65535+、Nginx 透传 Upgrade、多机 Redis Pub/Sub、异常关闭码监控
