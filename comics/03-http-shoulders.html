第三幕 · 站在 HTTP 的肩膀上 ​

对应主线教程：第 3 章 WebSocket 与 HTTP 的区别与联系

三种联系 ​

  1. 握手复用 HTTP：一个标准 HTTP GET + Upgrade 完成升级
  2. 共用端口：ws:// 走 80、wss:// 走 443，与 HTTP/HTTPS 一致——能顺利穿过绝大多数防火墙和代理
  3. 复用基础设施：Cookies、TLS 证书、Nginx 反向代理、负载均衡、网关鉴权原样可用

核心区别 ​

维度HTTPWebSocket
通信模式半双工，一问一答全双工，随时互发
连接性质短连接，逐请求持久长连接
头部开销每次几百字节帧头最小 2 字节
服务端推送不支持原生支持
状态无状态连接本身即会话
URIhttp:// / https://ws:// / wss://

选型三岔口 ​

  • 偶尔获取、CRUD、可被 CDN 缓存 → HTTP
  • 服务端单向低频推送（通知、工单提醒）→ SSE，更简单且自带重连
  • 双向高频、实时性要求高（聊天、协同、行情、游戏）→ WebSocket

真实项目中两者共存：HTTP API 负责登录与数据查询，WebSocket 负责实时推送。
