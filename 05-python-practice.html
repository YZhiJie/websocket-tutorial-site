第 5 章 实战二：Python 服务端与客户端 ​

Python 生态的主流选择是 websockets 库（asyncio 原生）。本章实现与第 4 章功能对等的聊天室，并验证跨语言互通。

5.1 环境准备 ​

5.2 服务端 ​

完整代码见 examples/python/chat_server.py：

python
import asyncio
import json
import websockets

connected = set()

async def handler(websocket):
    """每个客户端握手成功后，websockets 会启动一个 handler 协程。"""
    connected.add(websocket)
    try:
        # websocket 是异步迭代器，每次 yield 一条客户端消息
        async for message in websocket:
            msg = json.loads(message)
            payload = json.dumps(
                {"type": "chat", "nickname": nickname, "text": msg["text"], "time": now_ms()},
                ensure_ascii=False,   # 关键：否则中文会被转义成 \uXXXX
            )
            await asyncio.gather(
                *[ws.send(payload) for ws in connected],
                return_exceptions=True,   # 个别连接发送失败不影响其他人
            )
    finally:
        connected.discard(websocket)

async def main():
    # ping_interval/ping_timeout：库内置协议级心跳，无需手写定时器
    async with websockets.serve(handler, "localhost", 8080,
                                ping_interval=10, ping_timeout=20):
        await asyncio.Future()   # 永久运行

asyncio.run(main())

与 Node.js 的范式对比（理解这一点，就掌握了两种语言的核心差异）：

Node.js (ws)Python (websockets)
并发模型事件循环 + 回调（ws.on('message')）asyncio 协程（async for message in ws）
连接生命周期事件驱动：connection/message/close 分散注册一个 handler 协程贯穿始终，结构化清晰
心跳需手写定时器 + isAlive 标记ping_interval 参数内建支持

5.3 客户端 ​

完整代码见 examples/python/client.py，亮点是指数退避自动重连：

python
async def main():
    attempt = 0
    while True:
        try:
            await connect_and_run()
            break
        except (websockets.exceptions.ConnectionClosed,
                websockets.exceptions.InvalidHandshake,
                OSError) as e:
            attempt += 1
            # full jitter 指数退避：1s → 2s → 4s … 封顶 30s，再乘随机数
            delay = random.uniform(0, min(30.0, 1.0 * 2 ** (attempt - 1)))
            print(f"连接异常: {e}，{delay:.1f}s 后第 {attempt} 次重连...")
            await asyncio.sleep(delay)
